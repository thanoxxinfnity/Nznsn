## Tips (image/text -> 3D ke liye)
- Ek image mein SIRF ek cheez, saaf background. Variants alag-alag image/seed se.
- Characters (RIG wale): full body, **T-pose**, saamne dekhte hue, haath-pair alag dikhen (rig achha banega).
- Darwaaze: sirf darwaaze ka patra (door leaf) banao, frame nahi — main Godot mein hinge laga dunga.
- Bade set-pieces (ferris wheel, bus, metro): chhota-detail theek, hum door se dikhayenge.
- File naam: `ID_naam.glb`, jaise `M01_gudiya.glb`. GLB format best (texture ke saath). Ek file < 15 MB.
- Tris_budget wo hai jo phone par chalega; AI ka model bhari aaye to main Blender mein khud halka kar dunga.
